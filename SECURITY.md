# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| main    | ✅        |

## Reporting a Vulnerability

- Email: security@example.com
- Alternatively, open a private GitHub Security Advisory if available.

Please include:
- A clear description of the issue
- Steps to reproduce
- Any known mitigations or workarounds

## Response Targets

- Initial triage: within 7 calendar days
- Fix or mitigation: within 30 calendar days when feasible
- Status updates: provided at least once every 14 days until resolved

We appreciate coordinated disclosure and will credit reporters unless anonymity is requested.
